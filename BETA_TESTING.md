# Public beta testing

Open: <https://jml845.github.io/seven-up-scorekeeper/>

## Install

- Android: open the link in Chrome, then use **Install app** or **Add to Home screen**.
- iPhone: open the link in Safari, tap **Share**, then **Add to Home Screen**.
- Desktop: open the link in Chrome or Edge; installation is optional.

## Suggested checks

1. Add several players and start a game.
2. Score rounds in both Quick Score and Card Calculator modes.
3. Close and reopen the browser or installed app; confirm the active game remains.
4. Finish a game and check History and All-time Stats.
5. Turn off internet access after the first successful load and confirm the installed app still opens.
6. On a supported Chrome/Android or desktop device, test Chromecast availability and live scoring.

When reporting a problem, include the phone model, operating-system version, browser, whether the app was installed, the screen involved, and a screenshot if possible.

## Beta limitations

- Data is stored only in that browser on that device. Clearing site data or uninstalling may remove it.
- Backup/import and cross-device sync are not included yet.
- Launching Google Cast from iPhone browsers is not currently supported.
