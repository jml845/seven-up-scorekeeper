# FlipCast beta feedback form specification

Keep the form short enough to complete immediately after one game. Do not require a name or email.

## Required questions

1. Did you try FlipCast during a real game?
   - Yes, completed the game
   - Yes, but did not complete it
   - No, only explored the app

2. What did you use to keep score?
   - Android phone/tablet
   - iPhone/iPad
   - Windows computer
   - Mac
   - Chromebook
   - Other

3. Did you attempt to cast to a TV?
   - Yes
   - No

4. If attempted, what happened?
   - Connected and stayed connected
   - Connected, then disconnected or froze
   - TV appeared but would not connect
   - No Cast device appeared
   - Other

5. Was score entry easy to understand?
   - Very easy
   - Mostly easy
   - Difficult
   - Could not complete scoring

6. Did you notice any incorrect score or game behavior?
   - No
   - Yes — explain below

7. Would your group use FlipCast again?
   - Definitely
   - Probably
   - Probably not
   - Definitely not

8. What should be fixed or improved first?
   - Short answer

## Optional questions

9. Phone/computer, browser, and Cast/TV model
   - Short answer

10. May we quote your comment when describing the beta?
    - Yes, anonymously
    - Yes, with the name I provide
    - No

11. Name or email for follow-up
    - Optional

## Hidden fields

- Build
- Browser/user agent
- Installed app versus web browser
- Campaign/recruitment source

## Completion message

Thanks for testing FlipCast. Your response will be used to improve the free beta. If you reported a Cast failure, keep the device and browser details handy in case we need to follow up.
